Project code for the LLM slang stagnation project. Divided into three main chunks
1) CCAnalysis: Scripts used for in depth analysis of common crawl data to try and grasp slang representation in model training data.
2) CommonCrawlDiff: Mostly holds data pulled from AWS runs as well a few experimental scripts for processing and displaying Common Crawl analysis data.
3) PromptingSlang: Scripts for prompting models trying to establish a dataset representitive of their bias toward using different parts of slang vocabulary.
